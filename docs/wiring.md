# 接线说明

## 数据流

```
+-------------+   USB    +---------------+   PWM    +-----------+   RC LPF   +-------------+
|  Ubuntu PC  |--------->|  ESP32-WROOM  |--------->| GPIO25/26 |----------->|  Voltmeter  |
|  Python     |  serial  |  parse + PWM  |          |   3.3V    |  1k +10uF  |   0..Vfs    |
+-------------+ 115200   +---------------+          +-----------+            +-------------+
```

## 一表通用接线 (CPU 一路, GPU 一路同理)

```
                       1 kΩ
   ESP32 GPIO25 -----/\/\/\----+------------ 电压表 (+)
                                |
                                === 10 µF (电解, 长脚正极接 GPIO 侧)
                                |
   ESP32 GND --------------------+------------ 电压表 (-)
```

GPU 那一路完全同结构, 把 `GPIO25` 换成 `GPIO26`.

## 元件选择

| 项 | 推荐 | 说明 |
| --- | --- | --- |
| 电压表 | **满量程 0~3V 或 0~3.3V** 的 85C1 / DH-670 系列指针表 | 直配 ESP32 PWM, 不需要放大器 |
| 滤波电阻 R | 1 kΩ, 1/4W | 与下面电容形成 fc ≈ 16 Hz 的低通 |
| 滤波电容 C | 10 µF 电解 | 16V 即可, 数值无需极精确 |
| 杜邦线 | 公对公若干 | 接面包板用 |
| 面包板 | 半尺寸即可 | 验证完可移到万能板 |

## 截止频率

RC 低通的 -3 dB 频率为

$$f_c = \frac{1}{2\pi RC} = \frac{1}{2\pi \cdot 1000 \cdot 10\times10^{-6}} \approx 15.9 \text{ Hz}$$

PWM 频率为 5 kHz, 比截止频率高 300 倍, 滤波后剩余的纹波 <1%, 指针不会"哆嗦".

## 关于 5V/10V 大量程电压表

ESP32 GPIO 最高 3.3V, 直接接 5V 量程的表, 100% 占空比时指针只能到 3.3/5 = **66% 位置**.

两种解决方案:

1. **重画刻度纸**(推荐) -- 把表的 0~5V 刻度替换成 0~100% 占用率, 然后软件里把"满偏"对应到 100% 即可. 实际只用了表头 0~3.3V 的范围, 但因为是模拟表, 这没问题.
2. **加运放** -- 用 LM358 做同相放大, 增益 = (Vfs / 3.3), 把 0~3.3V 升压到 0~Vfs.

## 调试技巧

第一次接表前, 先用**万用表**测 RC 滤波后的电压:

1. 上位机里运行 `python host/main.py --dry-run --echo`, 确认 CPU/GPU 数值正常.
2. 烧好固件, 让上位机正常发送, ESP32 串口监视器会回显 `[rx] cpu=xx gpu=yy`.
3. 用万用表 DC 电压档接在 (滤波后的导线 -- GND), 看跑满电脑时电压是否接近 3.3V, 空载时接近 0V.
4. **确认线性后再把电压表串进去**, 否则容易撞针.
